Power BI Fundamentals

From raw data to an interactive analytical report: understand the engine, storage model, data flow, semantic layer and real-time capabilities behind Power BI.

01 · Power BI vs Excel

The important difference is not simply "Power BI has better charts". Power BI is designed around a semantic model and analytical query engine.

Spreadsheet
Excel

Cell-oriented analysis

Calculations are often organized around cells, formulas, worksheets, tables and workbook operations.

Business Intelligence
Power BI

Model-oriented analysis

Tables, relationships, measures, filters and a semantic model form the foundation of interactive analytics.

Core advantage
VertiPaq

Columnar analytical engine

Import models can use compressed in-memory columnar storage for fast analytical operations.

03 · RAM + VertiPaq + Columnar Compression

RAM

Imported data can reside in memory, reducing repeated disk access during interactive analytical queries.

More available memory can allow larger models and more concurrent workloads, subject to capacity and model constraints.

Columnar Storage

Values are organized by column rather than treating each complete row as the primary analytical unit.

This is particularly effective for aggregation-heavy workloads.

Compression

Encoding and compression reduce the physical size of model data.

Low-cardinality and repetitive columns can compress especially well.

Important misconception Power BI is not automatically faster than Excel for every task. Its major advantage appears when working with analytical models, relationships, aggregations, filtering and interactive reporting.

Basic Aggregations

SUM(Sales[Cost])

AVERAGE(Sales[SalesAmount])

Transaction Count =
COUNTROWS(Sales)

Customers =
DISTINCTCOUNT(Customer[CustomerID])

DIVIDE

Profit Margin =
DIVIDE(
    [Profit],
    [Total Sales],
    0
)

IF

Sales Status =
IF(
    [Total Sales] >= 1000000,
    "High",
    "Low"
)

SWITCH

Performance =
SWITCH(
    TRUE(),
    [Profit Margin] >= 0.30, "Excellent",
    [Profit Margin] >= 0.15, "Good",
    [Profit Margin] >= 0.05, "Average",
    "Poor"
)

CALCULATE

India Sales =
CALCULATE(
    [Total Sales],
    Customer[Country] = "India"
)
CALCULATE is fundamental It evaluates an expression in a modified filter context. Many advanced DAX calculations are built by controlling filter context through CALCULATE().

Medallion Architecture

A layered data architecture that progressively transforms raw source data into clean, validated and business-ready information through Bronze, Silver and Gold layers.

01 · What is Medallion Architecture?

Core idea Do not treat raw data and business-ready data as the same thing. Medallion Architecture separates data according to its level of refinement: Bronze → Silver → Gold.

BRONZE — RAW

SOURCE DATA · INGESTION · MINIMAL TRANSFORMATION

↓

SILVER — CLEANED

VALIDATED · STANDARDIZED · DEDUPLICATED · INTEGRATED

↓

GOLD — BUSINESS READY

BUSINESS LOGIC · KPIs · AGGREGATIONS · ANALYTICS

02 · The Three Layers

Layer 1

Bronze — Raw Data

The Bronze layer stores data close to its original source form.

Typical sources include ERP systems, CRM systems, APIs, IoT streams, CSV files, Excel files and operational databases.

Primary objective: preserve source information and maintain traceability.

Layer 2

Silver — Trusted Data

The Silver layer contains cleaned, standardized and validated data.

Typical operations include type correction, deduplication, standardization, validation and integration.

Primary objective: create reliable reusable data.

Layer 3

Gold — Business Data

The Gold layer represents information in a form optimized for business consumption and analytical workloads.

Business rules, KPIs, aggregations and analytical structures are typically introduced here.

Primary objective: deliver business-ready information.

04 · Bronze Layer — Technical Details

Source Preservation

Bronze data should generally retain the structure and values received from the source rather than immediately applying extensive business logic.

Ingestion Metadata

Useful metadata can include ingestion timestamp, source system, batch identifier, file name, ingestion status and processing date.

Traceability

Keeping source-faithful data makes it easier to investigate where a Silver or Gold value originated.

Historical Preservation

Bronze can provide a historical record of what arrived from upstream systems, depending on the retention strategy.

Example Bronze Record

{
    "customer_id": "C001",
    "customer_name": "ABC Ltd",
    "region": "south ",
    "sales_amount": "125000",
    "transaction_date": "15/08/2026",
    "source": "ERP",
    "ingestion_timestamp": "2026-08-16 02:15:10"
}
Bronze principle Avoid destroying useful source information too early. Transformation should not make the original data impossible to audit or reproduce.

06 · Gold Layer — Technical Details

The Gold layer is where the cleaned data becomes meaningful for a specific business domain or analytical workload.

Business Rules

Apply approved business definitions such as revenue, profit, margin, customer status or service-level measures.

Aggregations

Prepare summaries such as daily, monthly, regional or product-level metrics where appropriate.

Dimensional Structures

Gold data can be organized into analytical fact and dimension structures for BI consumption.

KPI Layer

Expose consistent definitions for business metrics so different reports do not independently calculate conflicting versions of the same KPI.

Time-Series Forecasting

Forecasting uses historical temporal structure to estimate future values. ARIMA models temporal dependence, SARIMA adds seasonality, and SARIMAX adds external explanatory variables.

01 · Anatomy of a Time Series

Trend

Long-term direction of the series.

Seasonality

Repeating pattern at a known frequency.

Autocorrelation

Dependence between observations at different lags.

Noise

Random variation not explained by the model.

Exogenous Variable

External factor influencing the target.

Stationarity

Relatively stable statistical properties over time.

02 · ARIMA → SARIMA → SARIMAX

ARIMA

(p,d,q)

Autoregression + differencing + moving average.

→

SARIMA

(p,d,q)(P,D,Q)s

ARIMA + explicit seasonal structure.

→

SARIMAX

SARIMA + X

Seasonality + external explanatory variables.

03 · ARIMA

p

Autoregressive Order

Number of previous observations used to model the current value.

d

Differencing

Number of differences applied to make the series more stationary.

q

Moving Average Order

Number of previous forecast errors incorporated into the model.

ARIMA(p,d,q)

AR — Autoregressive component

yt = c + φ1yt-1 + φ2yt-2 + εt

I — Integrated component

Δyt = yt − yt-1

MA — Moving Average component

yt = μ + εt + θ1εt-1

07 · Stationarity

Stationarity means that important statistical properties of the modeled series remain relatively stable over time. Classical ARIMA-family models typically work with a stationary series after appropriate transformations.

Visual Inspection

Look for changing mean, changing variance and persistent trend.

Rolling Statistics

Compare rolling mean and variance across time.

ADF Test

Augmented Dickey-Fuller test provides a statistical test related to a unit root and stationarity.

11 · Time-Series Train/Test Split

TRAINING DATA
Past observations
TEST
Future-like observations
Do not randomly shuffle a conventional time series. A random split can allow future observations to influence training and produce an unrealistically optimistic evaluation.

12 · Forecast Accuracy

MAE

MAE = mean(|actual − forecast|)

Easy to interpret because it remains in the target variable's units.

MSE

MSE = mean(error²)

Large errors receive disproportionately higher penalty.

RMSE

RMSE = √MSE

Returns error to approximately the same units as the target.

14 · Model Selection Cheat Sheet

Use ARIMA

When the important structure is primarily non-seasonal temporal dependence.

Use SARIMA

When repeating seasonal behavior is an important component of the series.

Use SARIMAX

When seasonal behavior exists and external variables contain useful predictive information.
